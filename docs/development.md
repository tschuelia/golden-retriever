# Development

## Environment

The repository uses Pixi; required tools are intentionally not assumed to be on
the global `PATH`.

```console
pixi install
pixi run postinstall
```

The package targets Python 3.12, 3.13, and 3.14 and has no runtime dependencies.

## Tests and checks

```console
pixi run test
pixi run test-slow
pixi run -e py312 test
pixi run -e py313 test
pixi run -e py314 test
pixi run -e lint lint
```

The lint task runs Ruff, mypy, docformatter, Prettier, Taplo, typos, and zizmor.
All functions, including test helpers, require type annotations.

## Documentation

Material for MkDocs and mkdocstrings live only in the `docs` Pixi environment:

```console
pixi run -e docs docs-build
pixi run -e docs docs-serve
```

`docs-build` uses MkDocs strict mode. Pull requests build the site; pushes to
`main` build and deploy it through GitHub Pages.

After changing `pixi.toml`, run `pixi lock` and include `pixi.lock` in the same
review.

## Specification provenance

All RTF behavior must be derived from:

- [MS-OXRTFEX](https://learn.microsoft.com/en-us/openspecs/exchange_server_protocols/ms-oxrtfex/906fbb0f-2467-490e-8c3e-bdc31c5e9d35);
- [RTF 1.9.1](<https://learn.microsoft.com/en-us/previous-versions/office/developer/office-2007/dd351035(v=office.12)>); and
- [Code Page Identifiers](https://learn.microsoft.com/en-us/windows/win32/intl/code-page-identifiers).

Put a section citation beside every spec-derived source table or rule. Fixtures
must be hand-authored from the specification rather than copied from Outlook or
generated by another parser. This keeps expected behavior independently
auditable.

Adding a runtime dependency requires prior discussion and a license compatible
with the repository's MIT license. Documentation and development dependencies
remain isolated from the published package.

## Module map

| Module              | Responsibility                                 |
| ------------------- | ---------------------------------------------- |
| `tokenizer.py`      | Byte-level RTF tokenization                    |
| `detect.py`         | Bounded `\fromhtml1` / `\fromtext` recognition |
| `groups.py`         | Iterative group stack and destinations         |
| `fonts.py`          | Font-table parsing and resolved font metadata  |
| `codepages.py`      | Charset and Windows code-page mappings         |
| `charmap.py`        | Context-specific visible-character tables      |
| `emitter.py`        | Deferred byte decoding and Unicode assembly    |
| `deencapsulator.py` | HTML/plain-text extraction driver              |
| `html_meta.py`      | Optional HTML charset declaration helpers      |
| `result.py`         | Public immutable values and diagnostics        |

Source responsibilities reflect MS-OXRTFEX §§2.2.3.1–2.2.3.3 and the supporting
RTF 1.9.1 parsing requirements.
